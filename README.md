# Applied regression for business and economics analysis (Ph.D. short course)

Hendrik Jürges, University of Wuppertal

The topic of this short course is applied regression analysis for descriptive and causal analysis using micro data (time series methods are not covered). Starting from the basics of the (correct) interpretation of regression coefficients in simple linear regressions, we will expand the scope to more complex specifications and hence interpretations. This includes interaction terms and logistic regression. Thereafter, we move on to two important applications of models with interaction terms in causal analysis, differences-in-differences and regression discontinuity designs. 
All empirical examples will be done in the statistical programming language R in a way that is replicable by students. Although the course is not intended as an introduction to R, it might be helpful if students install R (https://www.r-project.org/) and the IDE RStudio (https://posit.co/download/rstudio-desktop/) on their computers. I will also briefly give an example for an effective workflow, from loading data to producing printer-ready graphs, tables, slides and documents.

This course is intended to be adaptive to students’ needs and interests. Topics can be expanded on the fly if need arises.

Topics:
1.	Simple linear regression
2.	Linear & non-linear transformations
3.	Binary dependent variables & multiple regression
4.	Logistic regression
5.	Differences in differences
6.	Regression discontinuity
7.	Using R effectively: R projects, R markdown & Co.

Additional topics (depending on time and interest):
8.	The counterfactual causal model
9.	Directed Acyclic Graphs: why and why not?
10.	Identification with observed covariates: inverse probability weighting, outcome regression and double robust methods
11.	Causal machine learning
12.	Instrumental variables
13.	Statistical inference with robust and clustered standard errors
